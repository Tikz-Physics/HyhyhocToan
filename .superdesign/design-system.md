# HyhyhocToan Learning Illustration Design System

## Product and audience

Vietnamese primary-school mathematics practice for children aged 6–10. The target is the Grade 1 “Numbers 0–10” lesson flow. Illustrations must clarify the mathematical relationship before decoration.

## Existing identity to preserve

- Friendly rounded `Nunito`/`Quicksand` typography.
- Warm amber/orange brand shell with white cards and slate text.
- Large tactile buttons, generous rounded corners and clear success/error colors.
- Mobile-first, touch-friendly and readable in landscape.

## Reference-inspired illustration language

Use the observed pedagogical patterns from the supplied Trạng Toán page without copying its copyrighted mascot or exact artwork:

1. Counting: large, evenly spaced familiar objects in a contained scene; one object equals one clear counting unit.
2. Quantity comparison: two equally sized labeled trays with aligned object rows so differences are visible immediately.
3. Number bonds: a total token above two part containers; the missing value has a dashed outline; add a row of concrete manipulatives beneath.
4. Number sequence: one horizontal path/train with identical-size number cells and a strongly highlighted missing cell.
5. Number line: show 0–10 with the target and predecessor relationship visually connected.
6. Feedback: reveal a short 2–3 step explanation after answering; never expose the correct answer before interaction.

## Visual rules

- Keep the existing light, warm HyhyhocToan theme; do not copy the reference site's dark navy surface.
- Use original code-native SVG/CSS/emoji illustrations, not downloaded reference assets.
- Object art: soft 3D sticker feel, subtle shadow, consistent size, no visual clutter.
- Illustration card: white-to-sky/emerald tint, amber or sky border, `rounded-2xl`, small inset shadow.
- Labels: concise Vietnamese, 11–14px, bold, high contrast.
- Answer area stays separate from the illustration area.
- Support 320px mobile width without horizontal overflow.
- Preserve all current curriculum text, answers and interactions.
- Respect reduced-motion preferences.
